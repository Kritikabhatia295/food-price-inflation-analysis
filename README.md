# Food Price and Inflation Analysis – India

## Project Overview

Food Price and Inflation Analysis is a Python-based Data Science project that explores historical food prices in India and identifies price trends and inflation patterns.

The project uses data analysis, visualization, and basic machine learning to understand how the prices of essential food commodities change over time.

## Objectives

- Analyze historical food prices in India.
- Clean and preprocess the dataset.
- Calculate average food prices.
- Study monthly and yearly price changes.
- Identify food commodities with higher inflation.
- Visualize food price trends.
- Demonstrate rice price trend prediction using Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Google Colab

## Project Features

1. **Data Cleaning:** Handles missing values, duplicate records, and data formatting.
2. **Price Analysis:** Calculates average prices of different food commodities.
3. **Inflation Analysis:** Examines monthly and yearly percentage changes in food prices.
4. **Data Visualization:** Presents food price trends through charts.
5. **Price Prediction:** Uses Linear Regression to demonstrate rice price trend prediction.
6. **Interactive Dashboard:** Allows users to select food commodities and explore their price trends and summary statistics.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/food-price-inflation-analysis.git
```

2. Open the project folder:

```bash
cd food-price-inflation-analysis
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit dashboard:

```bash
streamlit run app.py
```

## Dataset

The project uses a CSV dataset containing historical food price information.

The dataset is used to analyze commodity prices over time.

## Machine Learning

Linear Regression is used to demonstrate rice price trend prediction based on historical price observations.

**Note:** This is a basic trend-based prediction and should not be treated as a validated economic forecast.
